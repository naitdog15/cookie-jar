# Cookie Jar 1.0.0

- Date: 2026-10-17
- Platform: Windows

## Briefing

Establish a versioned Windows release with source-controlled patch notes and shared release rules for Codex and Claude.

## Changes

- Builds embed the application version and place generated `PATCH_NOTES.md` beside the executable, identifying its source branch/revision and local changes.
- Added a release-preparation command supporting major, minor, patch, alpha and beta versions, plus checks before builds and commits.
- This baseline includes the existing hardware-based targets (9 recommended / 12 default limit on the current PC), automatic session RAM allocation, and the explicit hardware-limit override.

## Source

- `VERSION`, `build.ps1`, `scripts/`, `.githooks/pre-commit`: versioning, checks and distribution notes.
- `AGENTS.md`, `CLAUDE.md`, `docs/RELEASE_POLICY.md`: shared agent workflow.
- `src/MainWindow.cs`, `src/Restrictor.cs`, `src/AutoRamPolicy.cs`: existing Windows session controls.

## Validation

- Windows release and development builds, embedded-version and generated-notes checks.
- Automated release-policy checks covering version increments, prerelease promotion and invalid metadata.
- Existing hardware/Auto RAM policy tests.

## Known limitations

- No live Roblox performance or interactive UI test for this release.
- macOS distribution version metadata and release-note copying remain a separate port task.
