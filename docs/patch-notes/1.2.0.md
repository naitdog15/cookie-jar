# Cookie Jar 1.2.0

- Date: 2026-10-17
- Platform: Windows

## Briefing

Add Focus mode: one instance goes fullscreen with the most CPU, and a lone instance now fills its monitor.

## Changes

- New Focus button on each running instance card (Unfocus when active). The focused window covers its whole monitor, taskbar included, and comes to the front; it runs at High priority on every processor while the other clients drop to Below Normal on the last quarter of the processors. Unfocus, the client stopping, or exiting the launcher restores the original priority and affinity, and Unfocus re-tiles.
- While Focus is on, Tile now and launch placement keep the focused window fullscreen instead of tiling.
- A single instance in normal tiling now fills the whole monitor instead of the inset work area, so one session can be fullscreen again.

## Source

- `src/FocusBoost.cs`: priority and affinity boost and restore.
- `src/WindowManager.cs`: `PlaceFullscreen`, single-window cell in `ComputeTiling`.
- `src/MainWindow.cs`: Focus button, `ToggleFocus`/`ClearFocus`, per-second upkeep, placement guard.

## Validation

- Windows build only. No live Roblox, window-placement or affinity test was run.

## Known limitations

- Other clients are limited to few processors while Focus is on, so they may load slowly or lag. Windows may refuse to change a protected process; this is logged once.
- Unfocus restores priority and affinity only for clients still running.
