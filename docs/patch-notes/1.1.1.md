# Cookie Jar 1.1.1

- Date: 2026-10-17
- Platform: Windows

## Briefing

Make updater checksum verification independent of inherited PowerShell module paths.

## Changes

- Replaced the updater's Get-FileHash cmdlet calls with .NET SHA-256 hashing, so verification works when Windows PowerShell inherits a module path from PowerShell 7.
- Includes the 1.1.0 Check for updates button, private GitHub access, isolated source builds, install confirmation and rollback.

## Source

- `scripts/install-update.ps1`: module-independent executable hash generation and verification.
- `tests/update-install-tests.ps1`, `tests/UpdateTests.cs`: installer and authenticated preparation checks.

## Validation

- Windows builds and isolated source-build, replacement, tamper rejection and rollback tests.
- Authenticated GitHub source download and build preparation verified through the actual spawned updater process, without installing or restarting the app.

## Known limitations

- No interactive application restart or live Roblox test. A private repository requires GitHub CLI installed and signed in with read access.
- Version 1.1.0's source build succeeds but its embedded verifier may fail under an inherited PowerShell module path. Use the 1.1.1 build as the updater baseline.
- Source staging and backups are retained for recovery; only immediate startup failures trigger automatic rollback.
