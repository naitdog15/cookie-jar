# Cookie Jar 1.3.0

- Date: 2026-11-15
- Platform: Windows

## Briefing

Export shareable diagnostic logs from the activity panel

## Changes

- Add **Dump log...** beside Clear in the activity log. Choose a location for a dated UTF-8 text report, then attach it to a support message.
- Include the installed version, export time, hardware/launcher state, tracked-client status, current and previous retained launcher logs, and current on-screen activity. Export runs in the background without stopping Roblox clients.
- Mask recognized credential-bearing lines and Windows user-folder paths. Do not collect account stores, browser data, Roblox logs or process command lines. Display names in activity can remain; review the file before sharing.

## Source

- `src/MainWindow.cs`, `src/MainWindow.Diagnostics.cs`: export button, save dialog, state snapshot and success/failure feedback.
- `src/LauncherLog.cs`, `src/DiagnosticReport.cs`: rotation-safe log snapshot, bounded history, redaction and text export.
- `tests/DiagnosticTests.cs`, `tests/build_diagnostic_tests.ps1`: isolated export, redaction and file-error checks.
- `README.md`: client instructions for saving and sharing reports, including Clear/history behavior.

## Validation

- `./build.ps1 -OutDir bin_dev`: passed the release check and Windows .NET Framework build.
- `./tests/build_diagnostic_tests.ps1`: 34 checks passed with C# 5 compilation. Covers missing/locked/shared logs, chronological history, truncation, Unicode output, credential/path redaction across all report sections, source preservation and save failures. No accounts, network or desktop input used.
- `git diff --check`: passed.

## Known limitations

- Only retained Cookie Jar logs are included; rotated-away history cannot be recovered. Each saved log is limited to its newest 1 MiB of complete lines.
- No live UI or Roblox test performed. Redaction recognizes known credential formats; review free-form activity before sharing.
