# Cookie Jar 1.4.0

- Date: 2026-11-15
- Platform: Windows

## Briefing

Launch the newest installed Roblox player, wait for or report Roblox updates instead of failing in a loop, and offer opt-in removal of an outdated per-user Roblox copy

## Changes

- Cookie Jar now launches the newest installed Roblox player (highest file version across per-user, machine-wide and scanned installs) instead of an out-of-date per-user copy, and re-checks before every account launch. The start-up log lists every player candidate and the chosen one.
- Before launching, it waits up to 120 s for a running RobloxPlayerInstaller and otherwise reports it. A profile stops before the next account while an installer runs, instead of failing in a loop.
- When Roblox starts an update instead of the game (or the update closes a running client), the launch is reported as "Roblox is updating" with the player path, instead of "exited before its account window was ready".
- New: a warning appears when a registered Roblox copy is older than the newest install. For a per-user copy, an opt-in "Remove outdated Roblox copy" button backs up the HKCU keys (.reg) to `%LOCALAPPDATA%\RobloxMultiLauncher\backups\<timestamp>\` and then removes the folder and the HKCU roblox-player, roblox and Environments keys. It never touches HKLM or Program Files, and refuses while Roblox runs from that folder.
- Retry messages no longer say "Update Roblox with all games closed".

### Manual steps for affected PCs

1. Wait for the stuck RobloxPlayerInstaller to finish, or end it in Task Manager. Close any "critical error" dialog.
2. After installing 1.4.0, Cookie Jar uses the newest copy (for example `C:\Program Files\Roblox\Versions\version-4ea8e85481e34f46`). Optionally press "Remove outdated Roblox copy" with all Roblox closed. Manual equivalent: `reg export` each of `HKCU\Software\Classes\roblox-player`, `HKCU\Software\Classes\roblox` and `HKCU\Software\ROBLOX Corporation\Environments\roblox-player` to a backup, delete those three keys, then delete the stale `%LOCALAPPDATA%\Roblox\Versions\version-f0ea5da9412f4e35` folder. Leave Program Files, HKLM, roblox-studio, logs and settings alone.
3. Alternatively, start Roblox once from a non-elevated browser, which updates the per-user copy.

## Known limitations

- The version comparison uses the file version; a Roblox build that ships the same version falls back to the source order.
- The installer check only sees processes named RobloxPlayerInstaller.
- Cookie Jar still runs elevated, so Roblox updates go machine-wide.
- The HKCU RegisteredApplications "roblox-player" value is left in place.
- The website (browser) launch path is not version-checked; it uses whatever HKCR roblox-player points to.
- The 120 s installer wait holds the launch lock.
