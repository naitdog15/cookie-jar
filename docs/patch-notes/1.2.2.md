# Cookie Jar 1.2.2

- Date: 2026-10-28
- Platform: Windows

## Briefing

Save the activity log to disk and record start-up diagnostics so launch problems can be reported.

## Changes

- Every activity-log line is also appended to `%LocalAppData%\RobloxMultiLauncher\launcher.log` (rotated to `launcher.log.old` past 512 KB). Lines contain no tokens or tickets.
- At start-up one line records the Cookie Jar version, whether it runs as administrator, the Windows version and the Roblox player path. Administrator rights are needed to close Roblox's single-instance handles, so this shows at once whether that is the problem.

## Source

- `src/LauncherLog.cs`: file log and start-up line.
- `src/MainWindow.cs`: `AppendLog` writes each line to the file; start-up line written after the manager is created.

## Validation

- Windows build only. The log file was not exercised in a running app.

## Known limitations

- Logging failures (read-only folder, locked file) are ignored silently.
